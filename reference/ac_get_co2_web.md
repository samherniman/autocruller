# Get data from indoorco2map.org

Get data from indoorco2map.org

## Usage

``` r
ac_get_co2_web()
```

## Value

A dataframe with up to date co2 measurements - "web version"

## Details

This function will download the version of building data that is
displayed on the website map

## Examples

``` r
if (FALSE) { # \dontrun{
ac_df <- ac_get_co2_web()
} # }
```
