# Get data from indoorco2map.org - "download version"

Get data from indoorco2map.org - "download version"

## Usage

``` r
ac_get_co2_download()
```

## Value

A dataframe with co2 building measurements

## Details

This function will download the version of building data that is
available using the "download" button on the website

## Examples

``` r
if (FALSE) { # \dontrun{
ac_df <- ac_get_co2_download()
} # }
```
