# Create a vector of values evenly spaced between 0 and 1

Create a vector of values evenly spaced between 0 and 1

## Usage

``` r
range01(x, ...)
```

## Arguments

- x:

  vector of values

- ...:

  other parameters passed to min() or max()

## Value

vector of values evenly spaced between 0 and 1 the same length as x
